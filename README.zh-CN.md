# SuperX

**读懂 X，边刷边核查。**

[下载 1.0.0](https://github.com/bwjoke/SuperX/releases/download/v1.0.0/SuperX.zip) · [Chrome 商店](https://chromewebstore.google.com/detail/superx/clcflilaihhnnglfamdblhopokpnlioo) · [更新说明](https://github.com/bwjoke/SuperX/releases/tag/v1.0.0) · [官网](https://superx.vip/) · [支持](https://github.com/bwjoke/SuperX/issues) · [English](README.md) · [隐私说明](PRIVACY.md)

SuperX 是 Chrome / Edge 扩展，通过 Grok 订阅登录、自己的 API Key 或官方本机 Grok Build 连接，核查 X 帖子中的事实主张。回答流式显示在紧贴信息流的完整右栏，跟随 X 的主题和字体，保留原帖布局。

**GitHub Stable/Latest：[1.0.0](https://github.com/bwjoke/SuperX/releases/tag/v1.0.0)——[下载安装 ZIP](https://github.com/bwjoke/SuperX/releases/download/v1.0.0/SuperX.zip)。** 这一里程碑版本整合浏览时自动核查与发布前主动核查草稿，支持图片输入和证据来源链接。Chrome 商店最后核验的版本仍为 **0.9.12**；本次 GitHub 发布不会自动更新商店。

浏览时，SuperX 直接调查事实主张、相关细节和证据，不先复述一遍原帖。核查自己的发帖或回复时，点击 Post／Reply 旁的圆形 **SuperX** 按钮，回答在编辑框下显示并跟随草稿语言。可以输入文字、添加支持的图片，也支持只有图片的草稿；空草稿时按钮禁用。SuperX 不会发布草稿。

已发布帖子及可用父帖、上级回复和引用帖的图片可作为图片输入。草稿核查仅在明确点击时读取最多四张 PNG／JPEG 附图（合计 8 MiB）；回复链和引用帖提供辅助上下文，草稿仍是核查目标。草稿中的视频附件不参与核查，传入的视频缩略图仅代表静态画面。图片不受支持或加载失败时会明确提示，不会静默改为只发文字。草稿文字、图片和结果仅保留于运行内存，不写入浏览历史、共享回答缓存或排障日志。详见[隐私说明](PRIVACY.md)。

三种连接方式依次为 **订阅登录 · The X Subscription**（默认）、**Grok API Key**、**本机 Grok Build · CLI / ACP**，各自保留设置，不会自动切换来源。推荐 **Grok 4.3／无推理** 用于边刷边核查，通常更快、更简洁，Token 消耗更低。模型权限及费用以账户为准；本机 Build 需支持图片输入。见[连接引导](docs/CONNECTIONS.md)。

提供十二种界面语言和十三份本地化软件包概要，默认回退英文；本机浏览历史可搜索近 24 小时看过的帖子及已有回答。使用 Manifest V3 和原生 JavaScript，浏览器内订阅登录及 API Key 模式安装无需构建或下载依赖。

## 功能

- 在原生发帖／回复编辑器主动核查自己的草稿，回答流式显示在工具栏下方。
- 核查已发布帖子及上级／引用上下文中的图片；草稿可附带最多四张 PNG／JPEG，也可只有图片。草稿视频附件不包含在内，视频缩略图仅为静态画面。
- 停止滚动后，帖子连续可见满 1 秒才自动分析；停留时间和 API 并发都可调整，默认并发为 3。
- 可选手动模式：关闭「自动核查帖子」后，只有点帖子旁的「核查」才会发请求，额度只花在你挑的帖子上。
- 连续右栏覆盖 X 原右栏，可随时收起、恢复原右栏。
- 一次流式请求直接进行 Fact Check，省去前置解释和重复的原帖摘要，优先给出有用的结论、证据及必要限制。
- 内置或自定义 prompt：帖子与草稿共用核查核心，新帖／回复各有可编辑的上下文说明，评论建议另有指令。新帖引用、回复链与原帖用于理解草稿，所写内容始终是核查目标，深度与证据标准一致。
- Auto 跟随帖子当前显示的语言，切换原文／翻译时同步；也可指定固定输出语言。
- 流式 Markdown、可点击出处、每条 Token 用量及模型详情。
- 一键生成三条一句话评论建议，点击复制，不自动发布。
- 本地答案缓存；事实核查失败时保留已收到的部分结果并显示具体诊断。
- 最近 24 小时的本机浏览历史，可搜索看过的帖子及已有回答和评论，重启浏览器后仍可查看。

AI 功能需要配置一种连接；本机浏览历史不依赖连接。订阅 OAuth 由扩展直接连接，本机模式使用官方 CLI 的 ACP 服务，均不点击 X 内置 Grok 按钮。X 内置 Grok 无需 Key 模式和链接自然解读模式已在 0.7.0 移除。

## 安装与升级

需要桌面版 Chrome 或 Chromium 版 Edge 120 及以上，以及所选模型／工具的使用权限。API Key 和 OAuth 均仅需浏览器；可选本机模式提供 Windows PowerShell 和 macOS 终端引导。OAuth 已在 Windows Chrome 实装测试；macOS、其他浏览器及本机 CLI 仍需各自验收。自动化测试不等于实机通过。

安装 Chrome 商店当前公开版本（最后核验为 0.9.12）；商店更新前，1.0.0 请按下方手动安装步骤获取：

1. 打开 [Chrome 商店中的 SuperX](https://chromewebstore.google.com/detail/superx/clcflilaihhnnglfamdblhopokpnlioo)，点击「添加至 Chrome」。
2. 打开「设置 → 连接」。新安装默认选择「订阅登录 · The X Subscription」：点击「登录 Grok」，在官方页核对短码并授权。也可改为「Grok API Key」或「本机 Grok Build · CLI / ACP」。三种来源分别默认 **Grok 4.3／关闭推理**。保存设置、启用 SuperX，再打开 X。
3. Chrome 自动管理扩展更新。如果已有解压安装的旧副本，先停用它以避免重复分析，再单独配置商店副本。

使用 Edge 或从 GitHub 手动安装时：

1. 下载 [**1.0.0 稳定版安装 ZIP**](https://github.com/bwjoke/SuperX/releases/download/v1.0.0/SuperX.zip) 并解压，或在 [Releases](https://github.com/bwjoke/SuperX/releases) 中选择其他预览／稳定版本。附加的 `SuperX-<版本>.zip` 和 `SuperX.zip` 内容完全相同。也可下载源码，使用其中的 `extension/` 文件夹。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 在 SuperX 设置中配置该版本支持的连接，保存、启用 SuperX 并刷新 X。1.0.0 支持订阅登录、API Key 和 CLI／ACP；归档的旧版本可能提供较少连接方式。

手动安装版升级时，将新版文件覆盖到实际加载的目录，重新加载扩展，再刷新 X。请把该目录放在固定位置。GitHub 自动生成的源码压缩包与 Release 附加的扩展安装包不同。

从解压版切到商店版属于另一安装，当前不自动迁移设置与 Key。请先停用旧安装，避免重复分析，再配置新安装。

## Grok 订阅登录

新安装在「设置 → 连接」默认选择「订阅登录 · The X Subscription」，点击「登录 Grok」。核对短码后，由你本人在官方 xAI 授权页确认权限，再返回 SuperX。Windows 和 macOS 均无需填写 API Key、安装 CLI 或额外 SuperX 程序。登录成功后只加载账号模型目录，不发送测试核查；三种来源分别默认 **Grok 4.3／关闭推理**，账号不提供该模型时，需要你明确选择可用模型，不会自动改成 4.7。

授权页可能显示 **Grok Build**，因为当前使用 xAI 共享的公开 OAuth 客户端，并非单独注册的 SuperX 授权身份，也不表示官方合作。套餐资格、模型、额度和费用以提供方现行规则及你的账号为准，不保证所有订阅均可用。具体流程见 [连接引导](docs/CONNECTIONS.md#grok-subscription-oauth--browser-only)。

新登录只请求 `openid offline_access grok-cli:access api:access`，不再请求 `profile` 或 `email`，扩展不获取或使用账号资料信息。已有登录不会自动退出；缩小新请求范围不会追溯缩减旧授权。

默认勾选「在本机记住登录」。可轮换的刷新 Token 使用独立 AES-GCM 密钥加密保存，加密密钥位于扩展 IndexedDB；访问 Token 仅保存在受限浏览器会话存储和内存中。无需 SuperX 密码，不使用浏览器同步。关闭记住登录后，本次登录只保留到浏览器会话结束。刷新结果无法确认或安全保存时，需要重新登录。退出 OAuth 不会清除已有 API Key 或本机 Grok 配置。详见 [隐私说明](PRIVACY.md)。

## Grok API Key 与费用

The X Subscription 用户可在 [Grok Dashboard → API Keys](https://grok.com/dashboard/api-keys) 创建 **Grok Inference** 类型 Key，而非默认的 **Cursor** 类型，并为 Chat 和所用模型授权。已有 [xAI 控制台](https://console.x.ai/) Key 继续可用。具体订阅权益、限额及费用以自己账号的 [用量页](https://grok.com/dashboard/usage) 和提供方规则为准，不承诺所有订阅均含免费或无限 API。

两种来源都填写在「设置 → 连接 → Grok API Key」，无需另选 Key 来源。展开「获取 Grok API Key 或查看用量」即可找到对应入口：订阅用量去 Grok Dashboard，按量付费用量和账单去 xAI Console，以创建 Key 的账户为准。保存 Key 仅确认本机存储，不代表已验证 API 权限或剩余额度。

符合条件的 The X Subscription API 使用计入订阅共享周额度；也可以在 [xAI 控制台](https://console.x.ai/) 创建 Key、购买按量付费额度，按 Token 和工具使用付费并管理账单。购买普通 API 额度不会自动提高处理优先级。[Priority Processing](https://docs.x.ai/developers/advanced-api-usage/priority-processing) 需要额外付费并明确启用；SuperX 当前使用标准请求。Priority 可能降低高峰期延迟，但不保证可用性。发送哪些数据及服务商如何处理，见 [隐私说明](PRIVACY.md)。

首次配置默认勾选「在本机记住 Key」。Key 在当前浏览器配置中自动加密保存，重启浏览器后自动恢复，无需设置密码或手动解锁。取消勾选并保存后，会删除密文和本机加密密钥，仅在本次浏览器会话中保留 API Key，不使用浏览器同步。「清除已保存的 Key」删除密文、加密密钥、旧版 Key 记录、会话凭据和缓存，但不改变保存偏好。

已选择记住 Key 时，已有明文 Key 和旧版仍可用的会话 Key 会自动迁移；加密保存成功后才删除明文记录。保存数据缺失或损坏时，需要重新填写一次 API Key。新版不解密旧版密码加密记录，旧记录仅保留到成功迁移、更换或清除 Key。自动加密可保护单独泄露的已存密文，不能保护整个浏览器配置或已被控制的设备；详见[隐私说明](PRIVACY.md)。

API 模式的请求由扩展后台直接发送至 `api.x.ai`，项目没有中转服务器；Key 不传入 X 页面的帖子脚本。启用 SuperX 后，分析使用你的 Key。清除或更换 Key 会取消排队与正在进行的请求，并清除会话缓存，但已发送的工作仍可能计费。请阅读 [隐私说明](PRIVACY.md)，尤其是在可能显示非公开帖子的页面。

所有可见帖子都可能产生付费分析。多个 X 标签页共用请求槽，超出并发的任务排队等待。已经开始的回答在滚出画面后继续生成，X 临时卸载帖子时也保留订阅；滑回来恢复原回答，不再重新请求。尚未开始的任务可在离开视野时撤出队列。取消中的请求在本机传输清理结束前仍占用名额；本机取消不代表服务端计算已停止。本机模式使用独立模型／推理设置，逐项执行队列，需要保持官方服务的终端打开，可在设置中检查连接。

API Key 和本机 CLI／ACP 的求证、评论遇到临时错误后等待 3 秒，每条任务最多额外重试 5 次。等待重试不占并发名额，之后重新排入共享队列，其他帖子继续处理。部分回答和已报告的用量跨重试保留。Key 无效、账户／余额限制、不支持的设置、输出上限或本机取消未确认等问题不自动反复请求。OAuth 在收到 HTTP 200、流中错误、未完成输出或超时后不自动重放生成；HTTP 401 拒绝可刷新授权一次后恢复请求一次。单条报错不会暂停整个队列。重试或手动重复请求可能产生额外用量和费用。

没有插件级条数上限或消费上限。多个标签页、搜索工具、重试和重新分析会增加调用。0.9.11 每次求证尝试使用一次生成请求，评论建议另用一次请求；检索和模型处理仍需要时间，同一请求也可能使用多次检索。插件不会自动启用收费的 Priority Processing、更改账户预算或切换模型。实际价格、用量及账单以对应的 Grok Dashboard 或 xAI Console 账户为准。

## 设置与运行方式

API 模式的模型和推理档位分别通过下拉框选择：提供 `grok-4.3`、`grok-4.5`、`grok-4.6`、`grok-4.7`，只显示各自支持的推理档位。Grok 4.3 和无推理分别标为「推荐」，通常更快、更简洁，Token 消耗更低；默认并发为 3；旧设置中的 4.5–4.7 保持低推理档位，已有自定义模型继续保留。更高档位可能增加延迟和 Token 用量，不会开启 Fast／Priority 加速。可设置 1–8 路并发；模型实际可用性取决于 API 账号。必须至少启用「X 搜索」或「网页搜索」之一。

「自动核查帖子」默认开启。关闭后只核查你选的帖子：右栏每条帖子显示「核查」按钮，点了才发请求。点过的核查不会因滚动被撤回，有缓存时直接复用。切换到手动时，尚未开始的自动核查会撤回，已开始的照常完成。草稿检查、评论和浏览历史不受影响。

「自动分析前停留（秒）」默认 **1 秒**，三种连接模式均生效。页面／信息流停止滚动后，帖子需持续可见满设定时长才自动分析；再次滚动会重新计时，尚未开始的排队任务也重新等待，已开始的请求继续处理。在 SuperX 右栏内部滚动回答不影响计时。可设置 **0–30 秒**并支持小数，**0 秒**恢复立即分析；手动重新分析和评论无需等待。浏览历史仍立即记录可见帖子，无需配置连接。只更改停留时间不会中断已开始请求。首次从旧设置升级时，会将原 0 秒／并发 4 一次性调整为 1 秒／并发 3；之后手动选择的 0 秒或并发 4 会正常保存。

内置与自定义模式都以原帖 URL 为核心上下文，要求工具获取包含 **Show more** 后文字的全文。可见正文、作者、媒体及引用快照是辅助输入。工具可能无法取得全文；插件不保证模型已完整读取线程或查看所有媒体。

SuperX 直接进行 **Fact Check**：读取原帖链接后，一次流式请求深入核查明确说法、合理隐含的事实前提及可查证细节，沿出处和背景、数字、比较、因果等相关角度继续调查，不再先解释、复述原帖或追加第二次求证。只在连接核查发现与原主张确有必要时最少引用原文；区分作者原话与推断，不编造主张或强行挑错，不将缺少证据当作错误的证明。有出处的答案仍可能出错。

自定义模式可编辑事实核查和评论指令，每项最多 12,000 字符；空白使用默认指令。保存只影响新任务，点击「重新分析」可更新当前答案。固定应用规则仍约束输出语言、来源材料的安全处理、避免重复原帖及评论输出格式。旧版解释设置不再选择额外生成步骤；已有历史中的旧解释与回答继续保留，按原规则到期或由用户删除。

语言设置分为两项，默认均为 Auto，互不影响。「Grok 回答的语言」优先使用 X 当前显示正文的有效语言标记，再根据作者当前显示的正文判断；引用帖和搜索资料不决定语言。选择固定回答语言后，不随原文／翻译切换。「SuperX 界面的语言」在 Auto 下跟随 X 的界面语言；还没打开过 X 时使用浏览器界面语言，也可以单独指定右栏、设置和弹窗的固定语言。支持 12 种界面语言，其余回退英文。只切换界面语言不会重新生成回答或中断正在进行的请求。

顶部箭头收起 SuperX，恢复 X 原右栏；点击边缘 Logo 展开。收起取消未开始的任务，已开始任务可能继续完成并保留结果。帖子离开视窗时撤出尚未开始的排队任务；已开始的回答继续生成，返回时恢复原任务。0.9.11 切换浏览器标签页后，也会保留已开始的核查、评论及其重试，回来后继续显示原任务；新的自动任务等信息流重新可见后再触发。刷新、导航离开或关闭标签页仍会停止该页任务；已发出的请求仍可能计费。

X 发帖／回复弹窗、放大媒体及全屏内容优先显示：SuperX 的右栏、顶部和展开按钮暂时隐藏，不再启动新的自动核查，已开始的请求可继续完成。关闭后恢复信息流及设定的停留等待。回答与来源链接使用当前深浅主题对应的固定蓝色，不再受个别帖子链接样式影响。

## Token 与缓存

结果顶部使用提供方返回的真实 Token 数据，包含当前事实核查和评论；悬停查看模型及分项。不累计先前重新分析或整个账号的用量。缓存注明原生成消耗与本次未新增消耗；缺失或未完成统计不按字符数估算。

完整结果在当前浏览器会话内最多复用 24 小时，最多 160 条、约 4 MB。缓存区分连接来源、OAuth 授权身份、帖子、模型、推理档位、目标语言、搜索设置、生成流程及实际使用的 prompt。切换来源或重新授权其他 OAuth 账号后，不复用之前来源／账号的回答、评论或历史生成内容；本机记录的帖子浏览仍保留。缓存放在受信任的会话存储；关闭浏览器或变更凭据会清除，升级时删除旧版磁盘缓存。后台启动和写入新缓存时清理过期数据，24 小时是复用上限，并非浏览器会话内的精确定时删除。可在设置中「清除缓存」。缓存具体内容见 [隐私说明](PRIVACY.md)。

## 浏览历史

可从右栏顶部、扩展弹窗或设置打开「浏览历史」。SuperX 和历史记录启用时，支持页面上实际可见的帖子立即记录，无需停留或填写 API Key。历史记录默认开启，同一帖子重复浏览会合并并移到最前，按最后浏览时间保留 24 小时。

历史在受限的 `chrome.storage.local` 中保存当前显示的帖子正文、作者、URL、语言、浏览时间，以及已有回答、出处、Token／模型信息和评论草稿。重启浏览器仍可查看，不加密、不使用浏览器同步，最多 1,000 条、约 6 MB；达到容量上限时，较旧条目可能提前移除。它不保存完整帖子存档或图片文件。打开历史、搜索或展开已有回答不会调用 API，也不会预加载远程图片；点击原帖或出处会访问相应网站。

可以搜索帖子、作者和已有回答，删除单条记录或「清空历史」。关闭「保存浏览历史」停止新增记录和回答更新，已有记录保留至到期。到期条目不再显示；后台启动、历史读写及每小时后台清理时移除过期数据。浏览器未运行、调度延迟或存储错误可能延迟实际清理，不保证精确时点删除。

历史独立于 API 答案缓存：清除缓存、清除／更换 Key 和结束浏览器会话不会删除历史；清空历史也不会清除 Key、答案缓存或 X 上已显示的回答。查看历史不会自动恢复分析。支持页面上看见的非公开或受保护帖子也可能保留，详见 [隐私说明](PRIVACY.md)。

## 后续方向

**让你的 AI Agent 也知道你在 X 上看过什么。** 一个未来方向是由用户主动选择，将浏览历史中的帖子和已有解读提供给自己的 AI Agent，作为后续研究、讨论和创作的上下文。当前版本尚未提供 Agent 接入。

## 常见问题

| 情况 | 排查方式 |
| --- | --- |
| 没有输出 | 确认已启用、所选连接已配置、至少一种搜索工具开启；安装或重载后刷新 X |
| 本机 Grok 无法连接 | 保持服务终端打开，核对已保存的端口／连接码，见[连接引导](docs/CONNECTIONS.md) |
| 输出语言不对 | 选 Auto 跟随当前显示正文，或改为固定语言；不同目标语言的缓存分开 |
| 求证未完成 | 展开诊断，检查输出上限、连接、语言不符、超时、限速或权限等原因 |
| 限速或模型繁忙 | API Key／本机模式的临时错误 3 秒后重试，最多 5 次；OAuth 不重放已接受的请求。其他帖子继续排队，手动重试前查看诊断 |
| OAuth 登录过期或刷新结果不确定 | 在设置中重新登录；不会改用已保存的 API Key，只在官方授权页确认短码 |
| 右栏布局异常 | 重载并刷新；报告页面类型、浏览器版本及去除隐私的截图 |

有出处的回答仍可能出错。「求证未完成」不代表原帖已经核实；重试中和耗尽重试后，部分结果仍标明未完成，必要时手动重试。
